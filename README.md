# Ownmind

开源、自托管的个人 AI agent 平台。部署到自己的服务器，用浏览器管理。

> 开发中（M1）。范围见 [docs/SCOPE.md](docs/SCOPE.md)。

## 本地开发
需要：Rust（stable，带 C 编译器）、Node.js 22、pnpm。

```sh
pnpm install
pnpm dev        # server :8787 + 管理页面 :5173
```

打开 http://localhost:5173 。
