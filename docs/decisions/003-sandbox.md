# 003 沙盒：独立常驻容器 + 容器内 Rust 执行服务

- 状态：已采纳
- 日期：2026-10-15

## 问题
agent 要执行命令、读写文件，且必须与宿主机隔离；部署目标是 Docker Compose 单机。

## 决定
Compose 中单独运行一个常驻沙盒容器，内含一个小型 Rust 执行服务（sandboxd）。主服务通过 Compose 内部网络调用它执行命令、读写文件。沙盒容器限 CPU、内存，只挂自己的工作目录卷。任何服务都不挂 docker.sock。

## 考虑过的方案（及放弃原因）
- 主服务挂 docker.sock 按需创建容器：agent 被提示注入后可控制宿主机。
- 主服务容器内直接执行：无隔离，可读到密钥与数据库。
- gVisor/Firecracker 微虚拟机：隔离更强，但对 2C4G 云主机和普通用户安装门槛过高，以后可作为可选加固。

## 后果
需要定义主服务与 sandboxd 之间的协议与鉴权（内部网络 + 共享令牌）；沙盒内环境持久化在工作目录卷中，可整体重置。
