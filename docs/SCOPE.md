# SCOPE

## 用户与场景
- 想拥有自己 AI agent 的个人：把本项目自部署到自己的云服务器，用浏览器远程打开管理页面使用和管理 agent（体验类似 Hark、Grok bot）。
- 之后可通过 App 连接同一部署（App 后续开发）。
- 待定：一个部署服务一人还是多人。

## 核心价值
开源、自托管的个人 AI agent：开箱即连主流模型供应商，预装常用工具和技能，数据在自己的服务器上。

## MVP 功能（草稿，追问中）
- 一键/简单地部署到云服务器
- 浏览器访问的管理页面（对话、管理 agent）
- agent 内核基于 pi（pi-agent-core），预设几家主要模型供应商
- 预设常用工具与技能

## 明确不做
- MVP 阶段不做 App（后续单独开发，但需预留连接方式）
