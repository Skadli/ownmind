# SCOPE

## 用户与场景
- 想拥有自己 AI agent 的个人：把本项目自部署到自己的云服务器，用浏览器远程打开管理页面使用和管理 agent（体验类似 Hark、Grok bot）。
- 之后可通过 App 连接同一部署（App 后续开发）。
- 一个部署只服务一个人（部署者本人），MVP 不做多用户账号。

## 核心价值
开源、自托管的个人 AI agent：开箱即连主流模型供应商，预装常用工具和技能，数据在自己的服务器上。

## MVP 功能（追问中）
- 部署：目标 2 核 4G Linux 云服务器；Docker Compose 一条命令装好，另提供一键安装脚本；填域名即自动签 HTTPS 证书
- 浏览器访问的管理页面：会话（聊天主界面）+ 设置（参照 Hark 设置页：个人资料、定时任务、账户、钱包、系统偏好、安全、反馈、关于、退出登录；账户/钱包/反馈的范围追问中）；登录：首次打开设置主人密码，可选 TOTP 两步验证（passkey 以后再加）
- agent 内核基于 pi；模型供应商按此顺序预设，主人在管理页面填自己的 API Key：
  1. 任意 OpenAI 兼容地址（覆盖通义、Kimi、本地 Ollama 等）
  2. 任意 Anthropic 兼容地址
  3. OpenAI、Anthropic、Google、DeepSeek、OpenRouter
- agent 核心能力：
  1. 多会话聊天
  2. 长期记忆
  3. 定时任务
  4. 联网搜索、抓取网页
  5. 在隔离沙盒里跑命令、读写文件
- 预设工具（8 个）：联网搜索、抓网页、执行命令、读文件、写文件、改文件、读写记忆、管理定时任务
- 技能格式：Agent Skills 标准（SKILL.md），兼容 Claude Code、pi-skills 现成技能
- 安装技能：在对话里给 agent 一个 Git 链接由它装进已装目录，或主人 SSH 上服务器拷入
- 预设技能与主人安装的技能分开存放：预设技能随版本发布、只读、随升级更新；主人安装的技能单独目录，升级不覆盖

## 明确不做
- MVP 不做多用户/多租户（单人部署；以后需要再扩展）
- MVP 不做浏览器自动化、不连第三方账号（如 Gmail），放第二个里程碑（最重、安全风险最大）
- MVP 不做 passkey 登录（以后加）
- 不在管理页面上传技能
- 管理页面不做记忆页和技能页：记忆和技能由 agent 自行维护
- MVP 不做 Hark 首页那种面板看板
- MVP 阶段不做 App（后续单独开发，但需预留连接方式）
