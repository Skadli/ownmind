# 写研究报告

1. 先和主人确认主题、读者与篇幅；信息够了就别多问。
2. 用 web_search 搜多个角度，用 web_fetch 读原文；结论必须以读过的页面为准，不要只看搜索摘要。
3. 在沙盒里建 `reports/<主题>/`，把要点与出处边读边记进 `notes.md`，防止上下文被压缩后丢失。
4. 交叉核对：关键数字与论断至少两个独立来源；对不上就在报告里写明分歧。
5. 输出 `report.md`：摘要（先给结论）→ 正文分节 → 局限与未确认之处 → 参考来源（标题 + 链接）。
6. 最后在对话里给出摘要和文件位置，询问是否需要调整深度或格式。
