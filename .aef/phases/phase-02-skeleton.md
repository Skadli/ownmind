# phase-02 行走骨架

## 目标
打通最薄的一条端到端链路，并装好迁移、门禁、部署。之后每个功能都在一个能跑的系统上做加法。

## 先读
AGENTS.md、docs/stack.md、docs/architecture.md、.aef/state.md。

## 用到的技能
aef-data、aef-gates、aef-ticket

## 产出（拆成 3–6 张票，一票一会话）
1. 脚手架与本地一键启动依赖
2. 迁移体系：一条命令在空库建好全部表 + 必需数据 + 首个管理员（凭据来自环境变量）
3. 登录 + 一个最简单的 CRUD（含权限与前端页面）
4. 门禁与 CI（先接 3 个：lint/类型、模块边界、迁移不可变 + 空库迁移）
5. 部署到一个环境，先迁移后发版，健康检查

## 完成标准
新机器按 README 一条命令跑起来；部署环境能登录并完成 CRUD；门禁演示过会拦截违规。

## 不要做
不做第二个业务功能；不提前优化。
