# 两轴评审

两条轴分别在独立的上下文中进行（两个子代理或两个会话），互不看对方结论。小票可以一次评审同时看两轴。

## 规范轴
- 是否违反 AGENTS.md 的硬规则与模块边界
- 命名是否使用 GLOSSARY 词汇
- 数据变更是否符合 aef-data 与 aef-data
- **过度工程检查**：多余的空判断与兜底、吞掉的异常、只有一个实现的接口、没人用的参数和分支、兼容垫片——发现即要求删除
- 测试是否测行为、是否使用真实数据库

## 需求轴
- 每条验收条件是否有对应测试且通过
- 是否做了票之外的事
- 边界情况是否符合 spec 和 GLOSSARY 的定义

## 输出
每条意见标注：阻塞 / 建议 / 疑问，附文件位置与理由。无阻塞意见才可合并。
