# 复盘

1. 列出本迭代 AI 的返工、门禁失败、评审阻塞意见、线上问题。
2. 对每一类问题问：下次怎样让它不可能发生或更早被发现？
   - 能机械检查 → 新门禁（aef-gates）
   - 是认知问题 → AGENTS.md 一条带理由的规则，或补充 GLOSSARY / 模块 README
   - 是流程问题 → 修改对应 phase 或 skill
3. 反向检查：哪些规则或流程本迭代只增加了负担、从未拦住问题？降级或删除。
4. 检查 AGENTS.md 硬规则是否仍 ≤15 条。
5. 记录：本迭代的改进写进 state.md 的“最近变更”。

完成标准：至少一条具体改进，或明确“无需改进”并说明理由。

## 架构体检
每个里程碑结束（不是每个迭代），按 health-check.md 做一次体检，产出放进下个迭代的票。
