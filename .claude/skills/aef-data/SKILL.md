# 数据

数据上线后最难改，所以这里的规则比代码更硬。按需读两个参考文件：
- 设计表、字段、关联、索引 → 读 data-model.md
- 写迁移、种子数据、首次部署、升级 → 读 migration.md

## 五条硬规则（任何技术栈都适用）
1. 每张表只属于一个模块，只有它能写；表名带模块前缀。
2. 模块内可建外键；跨模块只存 ID，不建外键。
3. schema 只通过迁移改变；已合并的迁移不可修改。
4. 破坏性变更走 expand → migrate → contract，每步兼容上一版代码。
5. 空库必须一条命令建好全部表和必需数据；默认账号密码不进仓库。

## 技术栈
具体的迁移工具、命名格式、命令以 docs/stack.md 为准；没有 docs/stack.md 时只遵守上面的通用规则，不要自行选型，先提醒用户用 aef-stack 定栈。
