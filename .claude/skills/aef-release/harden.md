
# 加固

## 安全
- 依赖漏洞扫描、密钥扫描接入 CI
- 认证与授权：每个接口都声明了权限；越权测试（换一个用户/租户访问）
- 输入校验在系统边界；SQL 全部参数化；文件上传限制类型与大小
- 默认账号与默认密码不存在

## 性能
- 先测量：对关键路径压测，记录基线
- 常见问题依次排查：N+1 查询、缺索引、无分页的大查询、同步调用外部服务
- 优化后再测，结果写进记录

## 可观测性
- 结构化日志，带请求 ID 与用户/租户 ID（不记录敏感数据）
- 健康检查（活着）与就绪检查（依赖可用、schema 版本匹配）
- 关键指标与告警：错误率、延迟、队列积压

## 可恢复性
- 自动备份；**真实演练一次恢复**，记录耗时
- 写明数据丢失与停机的可接受范围

不要做没有测量依据的优化。
